# Feature Blueprint

## Core

- Responsive landing experience
- Educational content pages
- Search and navigation
- Financial terminology/reference content
- Resource links
- Clear disclaimers and source attribution

## Interactive tools

Possible future additions:

- SIP/compound-growth calculator
- Inflation calculator
- Goal-planning scenarios
- Risk/return visualisations
- Investment-product comparison framework

Interactive calculations should show formulas, assumptions and limitations rather than presenting a single number as a guaranteed outcome.

## Data features

Potential integrations include:

- Official public disclosures
- Regulatory/investor education resources
- Public market datasets where licensing permits
- Company financial information from authoritative sources

## Accessibility

- Keyboard navigation
- Semantic HTML
- Sufficient contrast
- Visible focus states
- Responsive typography
- Screen-reader-friendly labels

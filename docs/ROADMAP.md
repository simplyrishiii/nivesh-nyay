# Roadmap

## Phase 1 - Foundation

- Establish frontend framework
- Define design system
- Add core navigation and content model
- Add source/disclaimer conventions

## Phase 2 - Interactive experience

- Add search and filtering
- Add calculators and scenario tools
- Add structured resource pages
- Add responsive and accessibility improvements

## Phase 3 - Data integrations

- Connect authoritative public data sources
- Add validation and caching
- Display source and freshness metadata
- Add graceful degradation for provider failures

## Phase 4 - Production hardening

- Automated testing
- Security review
- Performance optimisation
- Monitoring and error reporting
- Deployment pipeline

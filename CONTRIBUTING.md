# Contributing

## Development principles

- Keep changes focused and reviewable.
- Prefer small reusable components and services.
- Document new external integrations.
- Do not commit credentials or personal data.
- Add tests for non-trivial business logic.
- Cite authoritative sources for financial claims.

## Pull requests

Include:

1. What changed
2. Why it changed
3. How it was tested
4. Any new environment variables
5. Any known limitations

## Financial content

Content that could influence financial decisions should include appropriate source attribution, dates where relevant, and clear limitations.
